# 最终报告 — 个人网站

## 1. 项目定位与目标用户

本网站是吕雪薇的个人简历型网站，面向同学、教师与未来项目伙伴，展示学业背景、技能方向与项目实践。

- **一句话定位：** 正在学 AI 开发的信管学生
- **目标访问者：** 课堂同伴、授课教师、竞赛合作者
- **核心印象：** 具备编程基础与金融分析思维的深大信管新生

## 2. 模板选择

| 项目 | 内容 |
|------|------|
| 模板 | [sproogen/modern-resume-theme](https://github.com/sproogen/modern-resume-theme) |
| 选择原因 | 课堂推荐零基础优先，结构清晰，内容通过一个 `_config.yml` 文件管理，修改成本低 |
| 保留内容 | 整体布局、响应式框架、样式体系 |
| 修改内容 | `_config.yml` 中的全部个人信息、技能、项目、经历、教育、活动内容 |

## 3. AI 协作过程

| 阶段 | AI 参与 | 人工判断 |
|------|---------|---------|
| 需求定义 | 根据用户描述起草 PRD、Design、Checklist | 用户确认范围与隐私边界 |
| 模板安装 | 克隆模板、推送至用户仓库、启用 Pages | 用户提供 GitHub 凭据 |
| 内容填充 | 根据简历信息整合 `_config.yml` | 用户确认内容真实性与公开范围 |
| 样式调整 | 尝试淡蓝色配色（后还原） | 用户决定保持原版配色 |
| 文档写作 | 生成 README 与最终报告 | 用户确认提交 |
