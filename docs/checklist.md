# 验收清单 (Checklist) — 个人网站

> 每项必须拿到可验证的证据后才勾选完成。
> [ ] = 待完成，[x] = 已完成

## 内容验收
- [ ] Hero 区块显示姓名「吕雪薇」和一句话定位
- [ ] About 区块包含真实的个人简介和专业背景
- [ ] Projects 区块列出至少一个真实项目或课程作品
- [ ] Skills 区块列出 C++ 和学习中的 AI 方向
- [ ] Contact 区块提供 QQ 邮箱联系方式
- [ ] 不存在模板占位文字或虚构经历

## 功能验收
- [ ] 导航菜单可点击，跳转到对应区块
- [ ] 项目链接可访问（如有外部链接）
- [ ] 联系方式（邮箱链接）可点击
- [ ] GitHub 链接指向用户真实仓库

## 显示验收
- [ ] 桌面端（≥1024px）无横向溢出
- [ ] 手机端（≤375px）文字可读、按钮可操作
- [ ] 无明显颜色或布局异常

## 工程验收
- [ ] README.md 包含项目说明和 Pages 链接
- [ ] docs/prd.md、docs/design.md、docs/checklist.md 三份文档齐全
- [ ] 至少 3 次有意义的 Git Commit
- [ ] report/final-report.md 最终报告完成
- [ ] screenshots/ 包含桌面、手机、Pages 和 Checklist 截图

## 发布验收
- [ ] GitHub Pages 已启用并可公开访问
- [ ] README.md 和 final-report.md 均记录正式链接
- [ ] 无痕窗口或另一设备可正常打开
- [ ] 无敏感信息泄露
