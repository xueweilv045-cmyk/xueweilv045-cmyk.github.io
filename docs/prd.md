# 产品需求文档 (PRD) — 个人网站

## 项目目标
建立一个可长期更新的个人简历型网站，展示学业背景、技能树与项目方向，作为学习历程的公开窗口。

## 目标用户与场景
| 用户 | 场景 | 最先寻找的信息 |
|------|------|---------------|
| 同学 | 课业合作、小组项目 | 技能方向、联系方式 |
| 教师 | 了解学生背景与进展 | 学习经历、项目实践 |
| 未来项目伙伴 | 寻找技术或协作搭档 | 技能清单、项目档案 |

## 本期范围
| 模块 | 内容 | 优先级 |
|------|------|--------|
| Hero | 姓名 + 一句话定位 | P0 |
| About | 个人简介、专业背景 | P0 |
| Skills | 掌握的编程语言与工具 | P0 |
| Projects | 学习中的项目 / 课程作品 | P1 |
| Contact | 公开联系方式（邮箱） | P0 |

## 本期不做
- 用户登录 / 注册功能
- 数据库或后台管理系统
- 支付功能
- 复杂动画或框架替换
- 采集访客隐私数据
- 公开手机号、身份证号、住址等敏感信息

## 成功标准
1. 页面可通过 GitHub Pages 公开访问
2. 五个基本区块齐全，无占位文字
3. 内容真实（本人经历、项目、技能）
4. 桌面端和手机端均可正常阅读
5. 导航链接和联系方式可用
6. docs/ 三份文档与最终网站内容一致
7. 过程材料（Git 提交、截图、报告）完整
