- 替换个人信息、项目经历、教育背景、技能与活动内容

- 添加 report/ 最终报告
- 添加 screenshots/ 证据截图

## 隐私说明

本仓库为公开仓库，仅包含本人同意公开的信息：
- 学校邮箱（用于联系）
- 真实姓名、专业、学校
- 项目与实习经历

不包含手机号、住址、身份证件、课程邀请码、API Key 或密码等敏感信息。

## 本地预览

本网站使用 Jekyll 构建，如需本地预览：

```bash
gem install jekyll bundler
bundle install
bundle exec jekyll serve
```

然后在浏览器打开 `http://localhost:4000`。
